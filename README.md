## 📌 Overview

**Shorty** is a URL shortener application focused on speed, simplicity, and presentation quality.
It converts long links into short, shareable URLs while maintaining a smooth user experience and clean UI.

This branch (`next_migration`) represents the migration toward a **Next.js-based architecture**, improving maintainability, routing consistency, and developer experience.

---

## ✨ Features

### 🚀 Core Capabilities
- Shorten long URLs into compact, shareable links
- Fast and intuitive link creation flow
- Clear input-to-output UX with minimal friction

### 🎨 UI & UX
- Modern and polished interface
- Responsive layout for desktop, tablet, and mobile
- Readable structure and consistent spacing/typography
- User-centric workflow with straightforward interactions

### 🧩 Engineering Focus
- Migration to Next.js App Router conventions
- Better project organization for scalability
- Production-ready structure for future enhancements

## ⚙️ Getting Started

### 1) Clone the repository

```bash
git clone https://github.com/Gavinduachintha/Shorty.git
cd Shorty
```

### 2) Checkout the migration branch

```bash
git checkout next_migration
```

### 3) Install dependencies

```bash
npm install
```

### 4) Run the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
